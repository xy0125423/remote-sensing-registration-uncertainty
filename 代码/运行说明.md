# 代码运行说明

## 无外部数据的汇总复核

在仓库根目录运行：

```console
python 代码/统计复核/复核关键结果.py
```

仅使用Python标准库，核对公开汇总表、五场等权与记录数量，并核对冻结图表文件摘要。不会重新计算严格质量规则、控制匹配或完整实验。

## 用户自备窗口的响应计算

```console
python 代码/主分析/运行分析.py --input 输入窗口.npz --output 新响应结果.csv
```

输入为不含对象数组的NPZ，字段A、B是11×11原生20米NBR数值数组；px、py为该窗口左上角起算的样地局部米制坐标，x向东、y向南；r_east_m、r_north_m为相对位移米数，北向在入口转换成数组南向。NBR由原生B8A/B12反射率计算，不是dNBR或放大1000倍的指数。输入应位于名义中心附近，保留完整邻域。

核心沿用四支持、五C、五λ、两指数，单窗口输出200个条件配置。不完整可达域标无效，不截断重归一。输出路径必须不存在。该入口没有自动重建140条入组记录、东侧匹配或控制删除流程；自备输入并非已验证与封版原始输入相同。

核心weights、state、evaluate函数及常量来自最终封版，数学函数体保持不变；移除了依赖本机私有目录的导入及全量实验调度，增加文档化的便携输入接口。未复制不可执行的历史调度脚本。图件重绘边界见[图件说明](图件生成/图件使用说明.md)。
