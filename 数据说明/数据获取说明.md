# 数据获取说明

1. 从[固定Zenodo记录](https://zenodo.org/records/21986637)取得RightOnTime_FinalArchive.zip，阅读上游说明及各来源限制。封版记录的原始归档MD5为2f6dc04c5a61d0caf2ee6aae6cb3ec5e。不要用更新版本静默替换冻结版本。
2. 在[Copernicus Data Space](https://dataspace.copernicus.eu/)按表1区域和火前、火后日期检索L2A产品。保留B8A、B12、SCL、原生transform及反射率尺度/偏移，不用可视化图替代定量数据。
3. 日期相同不保证产品、处理基线或像元窗口与封版完全相同。完整产品标识和原始窗口未在本仓库提供，因此此路线仅帮助获取上游材料，不能据此声称精确重建全部结果。
4. 对自备原生NBR窗口使用[运行说明](../代码/运行说明.md)。完整140记录的重新入组、控制匹配、27次删除和八图重绘还需要完整研究输入。

部分原始外业资料与位置已由上游省略，本项目无法提供其未公开部分。本仓库不自动下载数据。
